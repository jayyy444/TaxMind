# TaxMind 🧾

A smart tax filing assistant built with Python to help users understand, organize, and file their taxes with ease.

---

## Features

- Tax information guidance and Q&A
- Income and deduction tracking
- Filing checklist and reminders
- Simple and intuitive CLI interface

---

## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

```bash
git clone https://github.com/jayyy444/TaxMind.git
cd TaxMind
pip install -r requirements.txt
```

### Usage

```bash
python main.py
```
